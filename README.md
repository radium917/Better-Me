# Better Me

Better Me 是一个围绕个人目标、持续打卡和同目标陪伴设计的移动端优先 MVP。用户先创建自己的目标，再通过日常记录、心情、图片、统计和同行动态维持行动。

当前版本是纯前端演示应用，使用浏览器 `localStorage` 保存状态，并内置同行者、目标和打卡 mock 数据。

## 当前能力

- 手机号验证码注册/登录演示与完整首次引导
- 无需注册即可浏览同行动态和打卡详情
- 从预置模板创建每日或每周目标
- 文本、心情、相册图片或拍照打卡
- 发布后跳转「同行」并将新内容精确置顶
- 同行综合动态和按目标分类动态
- 点赞、评论、举报和拉黑
- 目标汇总、最近 5 周日历、历史打卡
- 每日目标与每周目标的独立连续规则
- 个人资料、目标管理、积分、勋章佩戴和兑换
- 通知偏好、隐私入口、退出登录与注销演示

项目已彻底移除小组、群聊、私信、关注和排行榜等功能。

## 技术栈

- React 18
- TypeScript
- Vite 5
- React Router 6
- Zustand 4 + persist
- Tailwind CSS 3

## 本地运行

要求 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

默认开发地址为 `http://localhost:5173`；端口被占用时 Vite 会选择下一个可用端口。

生产构建与预览：

```bash
npm run build
npm run preview
```

## 数据与限制

- 账号、目标、打卡、评论、积分等数据只保存在当前浏览器。
- 验证码、兑换、举报和通知均为 MVP 演示逻辑。
- 用户上传图片会在浏览器中压缩为 JPEG data URL 后持久化。
- mock 配图通过项目指定的图片生成服务加载，需要网络连接。
- 当前没有后端、跨设备同步、真实短信、云端图片存储或内容审核。

## 设计基准

- 移动端全屏；桌面端按 `390 / 844` 的 iPhone 逻辑比例展示。
- 主视觉为暖白纸面、中性色文字和低饱和绿色强调色。
- 信息密度按原生移动应用收紧，正文基准为 `15px`。
- 页面优先使用连续内容区、轻描边卡片和明确的层级，避免营销式大留白。
